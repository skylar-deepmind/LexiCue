Files and tags

Import SRT subtitles and organize them with tags. The learning-language filter determines which files appear.

Import an SRT file

  1. Choose Import in Files and select the subtitle file.
  2. Check the subtitle preview. Set the language you will learn; this is separate from the interface language.
  3. Select tags if needed and confirm. Open the resulting file card to read.

Organize and filter with tags

Selecting several tags shows files that match all selected tags. Deleting a tag removes its assignments, not the files.

  1. Open tag management to create, rename or delete a tag.
  2. Use a file’s tag editor to assign tags, then save.
  3. Select tags to filter, choose Untagged to find files without tags, or clear the filter to see all files in the current language.

Get YouTube subtitles

This is an online subtitle source, not a file format. Available subtitles and tool requirements depend on the video and platform.

  1. Open the YouTube entry in Files and provide the video link.
  2. Follow the available subtitle selection and preview, then confirm the learning language and import.

See alsoYouTube import

Back up and restore

  1. Open the file menu and export a backup. Keep the exported file in a safe location.
  2. To restore, choose the restore entry, select a LexiCue backup and read the confirmation before proceeding.

See alsoIs sync the same as a backup?
