Quick start

Read English with your own materials: import, understand on demand, save context and recall it on re-encounter.

Version and installation

This guide describes current main. Public v0.4.5 downloads for macOS, Windows and Android predate this workspace and Mac–iPhone sync. Use a newer release when available or build from source. iPhone has a locally tested signed build, but no public installer.

Download freeInstallation guide

Import and open a material

  1. Open Import from Materials. Choose a file, or paste English text, a webpage link or a YouTube link.
  2. Check the extracted text and selected pages or chapters where available, then confirm. Open the material card to read.

See alsoMaterials and tags

Save an encounter

  1. Select an unfamiliar word or passage. Read the meaning and save it with its original sentence; add a personal note if useful.
  2. Open Saved to find the record. When the expression appears in later reading, its highlight opens previous contexts.
