Quick start

Install LexiCue and start with one SRT subtitle file. No account is needed for local learning.

Download and install

  1. Open the release page and choose the package for your device: DMG for macOS, EXE for Windows, or APK for Android.
  2. On macOS, move LexiCue to Applications. On Windows, run the installer. On Android, install the APK with the permission required by your device.
  3. Launch the app. If the operating system blocks an unsigned package, follow the installation guide.

Download freeInstallation guide

Import your first subtitles

  1. In Files, choose Import and select an SRT subtitle file.
  2. Check the content preview and learning language, then confirm the import.
  3. Open the new file from the library.

See alsoFiles and tags

Look up and review a word

  1. Click a word in its sentence to open the definition.
  2. Mark a word you want to remember as Learning.
  3. Open Review, recall the meaning, reveal the answer and rate your recall.
