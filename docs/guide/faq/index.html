Frequently asked questions

Short answers to common installation and learning questions. Follow the linked chapter for the operation itself.

The app will not open after installation

Current packages are unsigned. macOS, Windows and Android may show different security prompts. Use the official release and follow the instructions for your platform.

Installation guide

Which files can I import?

File import currently supports SRT subtitles. If an import fails, check that the file has numbered subtitle blocks, valid time ranges and subtitle text. Renaming an extension does not convert a file.

See alsoImport an SRT file

Can I study offline?

Local reading, built-in dictionary lookup and review work offline. YouTube subtitle retrieval, model downloads, cloud AI and cloud sync need internet. Local AI works after a compatible model is ready.

Why is a definition or AI result missing?

Check the file’s learning language and the available dictionary sources. For AI, also check that it is enabled, a model is selected and the model or service is ready. Not every form or phrase has a result.

See alsoDictionariesAI analysis

Why are there no cards to review?

Check the current learning language and whether entries are marked Learning. A card may not be due yet; the next interval depends on its history and your ratings.

See alsoReview

Is sync the same as a backup?

No. A backup is an exported file you keep; sync carries learning records between connected devices. Export a backup before restoring or making major changes, and keep your sync recovery code separately.

See alsoBack up and restoreCloud sync
