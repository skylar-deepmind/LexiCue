インストール後に開けない場合

現在のパッケージは未署名で、macOS・Windows・Androidの警告は異なります。公式リリースを使い、環境別の案内を確認してください。

インストールガイド

取り込めるファイル形式は？

現在のファイル取り込みはSRT字幕に対応しています。失敗した場合は字幕番号、正しい時間範囲、本文を確認してください。拡張子の変更だけでは変換されません。

関連する操作SRTファイルを取り込む

オフラインで学べますか？

ローカルの読書、内蔵辞書、復習はオフラインで使えます。YouTube字幕の取得、モデルの取得、クラウドAI、同期はネットが必要です。ローカルAIは対応モデルの準備後に使えます。

語釈やAI結果が表示されない場合

ファイルの学習言語と辞書を確認します。AIは有効化、モデル選択、モデルまたはサービスの準備も確認してください。すべての語形やフレーズに結果があるとは限りません。

関連する操作辞書管理AI分析

復習カードがない場合

現在の学習言語と「学習中」の項目を確認します。カードがまだ期日でない場合もあり、次回の間隔は履歴と評価で決まります。

関連する操作復習

同期とバックアップは同じですか？

異なります。バックアップは保管する書き出しファイルで、同期は端末間で学習記録を引き継ぐ機能です。復元や大きな変更の前にバックアップし、復旧コードも別に保管してください。
