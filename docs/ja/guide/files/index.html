ファイルとタグ

SRT字幕を取り込み、タグで整理します。表示されるファイルは学習言語で絞り込まれます。

SRTファイルを取り込む

  1. 「ファイル」で取り込みを選び、字幕ファイルを指定します。
  2. 字幕を確認し、学習する言語を選びます。表示言語とは別の設定です。
  3. 必要ならタグを選んで確定します。作成されたファイルカードから読み始めます。

タグで整理・絞り込み

複数タグを選ぶと、すべてに一致するファイルだけが表示されます。タグを削除してもファイルは削除されません。

  1. タグ管理で作成・名前変更・削除を行います。
  2. ファイルのタグ編集からタグを付け、保存します。
  3. タグで絞り込みます。「タグなし」で未分類のファイルを探し、解除すると現在の学習言語の全ファイルが表示されます。

YouTubeの字幕を取得する

これはオンラインの字幕取得元であり、ファイル形式ではありません。字幕の有無や必要なツールは動画と環境によって異なります。

  1. 「ファイル」のYouTube入口から動画URLを入力します。
  2. 利用できる字幕を選んで確認し、学習言語を指定して取り込みます。

バックアップと復元

  1. ファイルメニューからバックアップを書き出し、安全な場所に保存します。
  2. 復元時は復元入口でLexiCueのバックアップを選び、確認内容を読んでから進めます。
