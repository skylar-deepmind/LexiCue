ダウンロードとインストール

  1. リリースページで端末に合う形式を選びます。macOSはDMG、WindowsはEXE、AndroidはAPKです。
  2. macOSではアプリを「アプリケーション」へ移動します。Windowsではインストーラーを実行し、Androidでは端末の許可を確認してAPKをインストールします。
  3. アプリを起動します。未署名のパッケージがブロックされた場合は、インストール案内を確認してください。

無料でダウンロードインストールガイド

最初の字幕を取り込む

  1. 「ファイル」で取り込みを選び、SRT字幕を指定します。
  2. 内容のプレビューと学習言語を確認し、取り込みを確定します。
  3. ライブラリから取り込んだファイルを開きます。

単語を調べて復習する

  1. 文中の単語を選び、語釈を確認します。
  2. 覚えたい単語を「学習中」にします。
  3. 「復習」で意味を思い出し、答えを表示して記憶を評価します。
