無料でダウンロードインストールガイド

素材を取り込んで開く

  1. 「素材」から取り込みを開き、ファイル、英語の本文、WebページやYouTubeのリンクを指定します。
  2. 抽出された本文を確認し、必要ならページや章を選んで確定します。素材カードから読み始めます。

関連する操作素材とタグ

出会いを保存する

  1. 分からない単語や表現を選び、意味を確認して元の文と一緒に保存します。必要ならメモを添えます。
  2. 「保存済み」で記録を確認できます。後の読書で同じ表現が強調表示されたら、以前の文脈を開けます。
