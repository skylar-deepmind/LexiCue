読書位置

素材の読書位置を保存し、デスクやライブラリから再開できます。同期された位置は次に素材を開くときに反映され、今読んでいるページは動きません。

以前の学習履歴

設定 → バックアップ → 履歴に以前の単語・フレーズ・復習記録を残し、閲覧・書き出しできます。新しい読書の保存文脈には自動で入りません。
