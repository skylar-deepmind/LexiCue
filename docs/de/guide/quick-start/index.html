Schnellstart

Lies Englisch mit eigenen Materialien: importieren, bei Bedarf verstehen, Kontext speichern und beim Wiedersehen erinnern.

Version und Installation

Dieses Handbuch beschreibt main. Die öffentlichen v0.4.5-Pakete für macOS, Windows und Android enthalten diesen Arbeitsplatz und die Mac–iPhone-Synchronisierung noch nicht. Nutze einen künftigen Release oder baue aus dem Quellcode. Das iPhone wurde lokal signiert geprüft; ein öffentlicher Installer fehlt.

Kostenlos herunterladenInstallationsanleitung

Ein Material importieren und öffnen

  1. Öffne den Import unter Materialien. Wähle eine Datei oder füge englischen Text, einen Webseiten- oder YouTube-Link ein.
  2. Prüfe den extrahierten Text und gegebenenfalls die Seiten- oder Kapitelauswahl. Bestätige und öffne die Materialkarte.

Siehe auchMaterialien und Tags

Eine Begegnung speichern

  1. Wähle ein unbekanntes Wort oder eine Passage. Speichere die Bedeutung mit dem Originalsatz und bei Bedarf einer eigenen Notiz.
  2. Finde den Eintrag unter Gespeichert. Taucht der Ausdruck später im Lesen auf, öffnet die Hervorhebung frühere Kontexte.
