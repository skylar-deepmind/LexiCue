# 学习进度 UI 优化与验证

日期：2026-10-06。

## 最终行为

- 桌面侧栏使用现有应用 Logo，宽侧栏保留 LexiCue 名称；手机不增加 Logo。
- 桌面掌握概览、七日复习和待复习提示合为一行，手机保留双圆环并排。手机页面标题与统计语言选择同行。
- 圆环表示单词／词组的四种状态分布，中心只显示已掌握比例；空词库显示“—”，不会显示虚假的 0% 或 NaN。
- 复习柱图按现有七日统计绘制，零值柱高为零。鼠标、键盘聚焦和点击可查看当天数量；全为零时显示紧凑空状态。
- 文件行合并名称、学习指数和详情。长文件名最多显示两行，完整名称和统计在文件详情中展示。保留 20 条分页。
- 全局详细统计集中展示词库数量、到期卡片、七日／累计复习和指标说明。文件详情保留原有学习指数及已掌握单词比例；未分析词组时提示并将词组数量显示为“—”。
- 详情复用 Overlay：桌面右侧面板，手机可扩展底部面板；支持遮罩、关闭按钮、Escape、返回协调器和焦点恢复。
- 复用现有接口、缓存和学习指数公式，无数据库迁移，无词库／复习快捷跳转。四种界面语言均已补齐。

## 验证结果

- 构建通过；186 项单元测试通过。
- 全量 lint 无错误，保留其他文件原有的 3 条 no-control-regex 警告；改动代码定向 lint 无警告。
- 完整浏览器回归 551 项通过。最后补充长文件名两行缩略、完整文件名与已分析词组详情检查后，统计页专项 288 项通过。
- 覆盖 ocean、amber、midnight，中／英／日／德文，320／390／768／1024／1440px，以及横屏和放大字体。
- 检查默认、悬停、选中、禁用和键盘焦点状态，相关交互文字对比度达到 4.5:1。
- 覆盖零数据、未分析词组、零值复习、加载／错误展示、分页、语言切换、展开、关闭、焦点圈定和恢复、模拟 Android 返回及减少动画。
- 测试采用独立内存 Tauri 夹具，不写正式学习数据库。截图输出到 `/tmp/lexicue-ui-check`。

开发服务器启动后，可使用 `LEXICUE_UI_INSIGHTS_ONLY=1 npm run test:ui` 仅检查统计页；完整回归使用 `npm run test:ui`。沿用 `LEXICUE_PLAYWRIGHT_MODULE`、`LEXICUE_UI_URL` 和 `LEXICUE_UI_OUTPUT` 配置。

以上验证为浏览器布局与交互检查，不等同于 macOS／Windows／Android 原生壳实机验收。原生环境仍需复核系统安全区、触屏、返回和原生 WebView 字体渲染。
