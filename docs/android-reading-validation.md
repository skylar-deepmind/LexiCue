# Android 词典与阅读修复验证

版本：0.4.2；验证日期：2026-10-05。本次在已有 Gemma 改造上增量实现，没有捆绑 Collins 资源，没有新增词典导入格式。

## 实现

- 初始化使用独立数据库连接和单个后台任务，不再重新执行主数据库建表与迁移。七份资源独立完成或失败，快照包含运行编号、递增序号、来源、处理条数和错误。每 2,000 行事务提交一次，整份导入完成后才记录来源完成标记；失败后的重试跳过已完成来源。启动时核对资源表，只有完成元数据但没有实际词条的来源会清除无效标记并重新准备。
- 前端先订阅、再获取快照；准备期间每两秒校准，失败的订阅会重新建立，回到前台会同步状态。失败不再永久显示“初始化中”。状态提示位于页面布局内，失败时提供原因与重试。
- `lookup_dictionary` 的 `mode` 默认 `local`。该分支只读取私有词典、用户词典、当前语言的内置表和已有在线缓存；ECDICT 已恢复为英文离线来源。损坏的私有词典或缓存不会阻断其他可用来源。联网查词只在用户点击“联网查询”后发起。离线结果保留本地发音文件，移除缓存中的远程发音 URL，避免播放时暗中联网；显式下载发音仍属于用户主动网络操作。详情页不再自动在线补充。
- 英文词组缺少私有词典释义时会读取并显示 PhraseDict，日语词组读取 JMdict Idioms。词组来源未准备完成时显示准备状态；来源完成会自动刷新当前详情。复习卡也使用四语内置离线查询，并丢弃过期卡片结果。
- `get_file_reader_tokens` 通过独立只读连接产生四种语言的完整词元、词形、UTF-16 原文范围及可选学习词条 ID。不写入学习词库，也不重编号 occurrence。完整词元用于原文排版；历史词元保留原位置锚点，没有学习 occurrence 的词元使用原语言定位规则补齐。旧词组映射优先于新增查词范围，覆盖只有部分单词入库的文件。
- 已入库词打开原有详情，未入库词打开临时查词面板。关闭、连续点词、切换文件时丢弃旧请求结果；重复词的上下文菜单保留实际点击位置。文件加载失败提供重试，读取期间不再扫描整个学习词库。
- 手机词库合并语言与单词／词组入口，常驻搜索、状态选择和筛选入口。排序、浏览方式、字体与额外选项位于共享底部面板；已启用额外条件显示明确摘要。批量操作仅在有选择或撤销操作时出现。手机分页为单行。
- 手机普通词条的状态按钮与词条并排，保留 48px 按钮触控区域。阅读设置集中到工具面板，搜索按需展开；返回操作先收起搜索并恢复焦点。弹层复用现有安全区、焦点与返回栈处理。
- 新文案覆盖中文、英文、日文、德文。新增表面与状态使用主题语义变量，覆盖默认和 midnight。
