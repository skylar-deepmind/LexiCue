# 模型删除与界面统一验收

日期：2026-10-02。设备：Apple M4、32 GiB，macOS。

## 实现结果

- 设置页管理全部本地 Ollama 模型，展示服务报告的大小、使用状态、删除确认及错误。删除通过原生接口完成，随后查询模型列表确认；云端配置和用户在等待期间的新选择保留。
- 后端以同一互斥状态保护删除、下载及本机生成任务，任务结束或失败时自动释放。包含使用 OpenAI 兼容协议访问本机服务的任务。新增本机活动事件及只读快照，前端先订阅再读取，按序号忽略旧状态。
- 模型列表刷新同步首页及设置页，按服务单独失效缓存，拒绝失效前开始的迟到查询。
- 九处选择器已统一为带主题浮层、键盘导航和可选本地搜索的组件。对话框拥有其浮层，并约束焦点循环。
- 文件标题两行省略，完整名称可悬停或键盘聚焦查看，操作区独立。文件网格按实际内容宽度换列。1359px 及以下窗口使用覆盖式分析抽屉，避免文件区受过度挤压。
- 文件卡片及进度页使用 48px 学习进度圆环。计算及阶段颜色保持原规则。进度页另显示已掌握单词比例，区分其与综合进度的口径。

## 真实 Ollama 与原生应用验证

- 为本机验收创建专用标签 lexicue-delete-validation:20261002，复用 llama3.2:1b，不下载权重。
- 使用实现中的删除客户端成功删除该标签，随后逐一核对原有 17 个模型的名称及摘要均保留，包括两个 Gemma 4 版本；未写入学习数据库。
- 最新本机调试包生成于 src-tauri/target/debug/bundle/macos/LexiCue.app。
- 原生应用在最新调试包中完成删除闭环：重新检测发现专用标签，取消确认后标签保留，确认删除后出现成功提示、列表自动恢复为 17 项，测试标签移除。Ollama 返回的全部原有模型名称和摘要与操作前一致，当前 Gemma 4 12B 选择保持。上次锁屏阻止的验证现已完成。

## 下拉菜单样式与宽度后续调整

- 选中项保留勾选和无障碍选中状态，取消底色及描边；悬停和键盘导航采用中性主题背景，搜索框和触发框样式沿用原设计。
- 弹出菜单按触发框外部宽度定位，移除 240px 最小宽度；尺寸观察覆盖触发框与浮层，保留窗口、滚动及视口边缘处理。
- 独立真实组件验收：模型框与菜单均为 272px；打开期间缩窄为 180px 后菜单同步；侧栏语言均为 134px；另外六处宽度相等；360px 窗口内导入选择器与菜单均为 273px，浮层位于对话框内且不越界。
- 默认与 midnight 主题的选中项均无背景、无阴影，保留一枚勾选。键盘搜索确认、End 定位末项、滚动、Escape 分层关闭和焦点恢复通过；禁用状态正常。
- 原生应用确认当前模型不在第一项时仍正常显示，首次展开没有错误滚到末尾；菜单宽度和选中样式已核对。最终前端 127 项测试、类型检查、生产构建、定向 lint 及本机调试包构建通过。
