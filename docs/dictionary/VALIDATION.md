## 来源与可复现性

词典唯一内容源为 English Wiktionary 的 English 部分，dump 日期 2026-10-01。采用 Kaikki **raw all-language** Wiktextract 提取数据，未采用前序被弃用的后处理英文快照。原始 gzip 的 SHA-256 为 `5ff2c072f8099f2d2ce484bd6957bf179f046d2ad37bc36555edf8bb84cb5291`。

固定版本 page/redirect SQL 与 9 个源码 XML 分片共约 5.05 GB 压缩输入均已校验，Wikimedia 文件同时与发布方 SHA-1 对照。流式核验 1,398,422 个英文页面，建立 89,906 条正向普通用例模板索引。没有落盘完整展开的全语言 JSONL/XML。每条实质记录绑定原页、修订号及页面 wikitext 哈希；每条保留例句绑定正向模板、修订号和源码行号。

准确的上游 Wiktextract 提取命令/commit 未随下载公布，明确记录为不可得；可复现范围是从 SHA 固定输入重建本包，不声称独立重跑了上游全站提取。原始数据 URL 可变化：下载器会拒绝不匹配的新字节，应保留输入缓存。源码核验缓存只应供同一版本与同一核验规则续做；修改规则或版本时使用新的任务输入根目录。

构建工具链为 Python 3.15.2 / SQLite 3.54.1 / zlib 1.2.12 / macOS arm64。ZIP 文件顺序、时间和权限固定。

重建核对：两份从相同固定输入和已核验源码索引生成的全新 SQLite 逐字节一致；完整 ZIP 也逐字节一致。重建没有复用最终 SQLite。详见 reproduction.json。

四个固定跳转为 get along with → get along、run out of → run out、a lot of → a lot、in charge of → in charge。没有删除介词来把 pay attention to 算作 pay attention 的准确命中。

`US` 的原始关系目标文字为 “the United States”；同版本源码的 place 模板明确指向 United States，且同一义项包含该链接，因此补入有修订号/行号/模板依据的目标。`US` 和 `U.S.` 均可到美国的实质释义；US 自己的 `/juː.ɛs/` 及 3 条普通用例保留在来源记录中。形容词义项用例另有词性和原始记录定位，不能和国家义项混配。`us` 保留其代词/限定词等内容，未通过大小写折叠串到 US。

`ran` 的独立名词义项不会遮住 run 的动词回查。`doomscrolling` 可返回独立名词释义及 doomscroll 的动词关系。`generative AI`、large language model 均有本地实质内容。`bank`、`run`、`dictionary` 的嵌套义项携带原有祖先链。完整真实查询输出（含失败）在 sample-entries.json。

## 质量、权利规则和限制

10 项离线回归和 27 项全量检查通过，覆盖 SQLite 完整性/外键、所有条目与别名终点的实质内容、祖先链、非法控制符/替换字符、来源修订、每条例句的正向源码证据、最终可执行路径连续性与无循环，以及定向验收项。源码中的 1 个损坏词头、1,309 个空/损坏/占位义项已省略；29 条不能绑定英文源码页的记录已省略。此字符检查并非对所有潜在乱码或释义准确性的穷尽人工审校。

原始关系图有 1,547,542 条边。解析发现 90,906 条不能到达包内实质目标的边；还有 4,196 个没有机器目标的关系义项。循环访问计数 3,051,342 是 DFS 路径访问次数，**不是独立循环数量**。循环路径被截断；最终可执行 aliases 的完整路径检查通过。原始不可执行跳转仍可在 redirects 和 build-audit 抽样证据中审查，不能当作成功命中。

普通例句要求 type=example、严格元数据白名单、同词头 English 源码中完整普通用例模板的正向匹配、来源/引文/媒体标记排除；还排除了 6 条与任意英文引文文本相同的候选。无 ref 不是许可核验结论。其余候选中的 636,023 条非普通示例、625 条未知/来源元数据、7,568 条无正向模板匹配均被排除。普通模板证明源站把它作为普通用例呈现，不能证明独立原创或完全排除上游未署名抄录；许可依据为贡献者 CC BY-SA 4.0，保留来源、修改记录与纠错入口。见 POLICY.md。

其他限制：保留技术、古旧、地区、冒犯性等原始义项和标签，没有学习者首义排名；并非每义项有例句或音标；没有动态短语/代词插入/搭配识别；MediaWiki English fragment 作为证据保存，但未实现按 fragment 精确限定义项；表层样本不是总体覆盖率承诺。rights 过滤与机器结构检查不能代替全部内容的人类审校。
