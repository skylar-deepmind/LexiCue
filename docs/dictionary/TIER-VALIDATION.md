## 基础包为何高于必备常用词

「日常通识」以一般母语阅读的熟悉程度为目标，覆盖生活、健康、文化、工作、公共事务、学校科学和现代技术，不是仅保留最初几千个学习词。
例如 pneumonia、monologue、soliloquy、eczema、chemotherapy、mortgage、satire、photosynthesis、quark 均有基础包实质解释。chickenpox → chicken pox、RNA → ribonucleic acid、pasteurized → pasteurise/pasteurize、hide-and-seek → hide and seek 也正确回查到基础解释，没有只留下关系壳。

基础包保留 53,164 条实质义项普通用例，以及 1,772 条关系页普通用例；保留原有发音、词性、用法标签和 16,999 个义项的祖先语境。来源中的英文解释与示例没有改写或截断。

按词头**和义项**分级：常见词的日常义项保留，窄学科义项可放入专业包；古旧/罕见义项主要进入进阶包。历史事物本身并不等于生僻词，`historical` 标签保留，但不会单独把熟悉概念排除。`archaic/obsolete/dated/rare` 仍作为可选层信号。例：monodrama 的生僻戏剧术语义项在进阶包；ichthyology、homeomorphism 等在专业包；盲文等专门符号资料不放进基础层。

## 可检查的收录依据

- wordfreq 3.1.1 的固定英文词频（Zipf ≥ 2.80）是信号之一；它描述约 2021 年以前的语料，不能独自判断今天的日常词汇。
- 补充公开可审查的健康、文艺、生活、学校科学、现代技术、常见表达清单；显式常见写法的真实别名目标也受保护。
- 一般复合短语不能只因组成词常见而进入基础包，还要求多个较近年代的原始源站引文记录；只保存计数和年份，不打包引文文本。常见表达和短语动词另有保留规则。
- 词性、地区/语体、窄学科标签、定义线索共同决定义项去向；具体规则和每个义项的原因在 tier-policy.json / selection-audit.jsonl.gz。

这是产品收录层级，不是对每个母语者词汇能力的测量。上游词频、用法标签和用例分布有偏差，边界仍需后续用户反馈校正。

全部释义与例句依然只来自原先已核验的英文 Wiktionary；词频数据不提供其他词典内容。保留 CC BY-SA 4.0、来源修订、修改记录，并追加 Robyn Speer / SUBTLEX 等词频数据署名。

## 接入边界

运行库 schema v2 使用共享数值 ID、来源定位池和逐记录 zlib JSON；只对查到的记录解压，单记录上限 8 MiB。完整路径证据留在开发审核库，运行库仍保留来源、修订、标签、正向目标确认和审计定位。

catalog.json 仅将 daily 标为默认包，另外两个为独立可选包；下载 URL 暂为空，未发布正式托管资源。实际 App 需要单独的本地适配器、安装与下载入口。它不能伪装成 Longman 或现有在线 Wiktionary 身份。原中文界面、在线查词和用户数据未改动。

本地数据库的实测体积并非 App 安装包总大小。接入时应避免多复制运行库，安装完成后释放临时 ZIP；手机/桌面安装、断网查询、收藏/同步及可选包启停仍需后续真机验收。

PR #8 保持草稿，未合并、未删除分支或发布 Release。完整构建证据在独立 build-review ZIP，普通使用只需默认的 daily ZIP。
