# 第一轮跨平台交互优化与验证

日期：2026-10-04。实现目标：Android 优先，共用桌面框架，保留路由与学习业务。

## 框架和交互约定

| 窗口宽度 | 主导航 | 文件夹树 |
| --- | --- | --- |
| 小于 768px | 五项底部导航，阅读时隐藏 | 明确按钮打开抽屉 |
| 768–1023px | 图标侧栏 | 抽屉 |
| 1024–1279px | 带文字侧栏 | 抽屉 |
| 至少 1280px | 带文字侧栏 | 常驻，可收起 |

- 五项主导航为文件、词库、复习、统计、设置。文件阅读归属文件。`/words`、`/phrases` 和原有深链接保留；词库记录最近分类，旧偏好默认单词。
- 手机和窄窗口提供学习语言入口，复用桌面的学习语言状态和复习切换确认。界面语言继续在设置中管理。
- 阅读顶部返回和 Android 返回使用同一协调器；恢复文件所属文件夹及该列表在本次会话中的滚动位置。
- `Overlay` 和 `useOverlay` 管理遮罩、层级、背景 inert、Tab 圈定与焦点恢复。Escape/Back 只关闭最上层。异步关闭期间继续消费 Back，失败保留编辑内容。
- `AdaptiveMenu` 在手机显示底部面板，桌面显示锚定菜单；词语详情默认手机半屏，显式展开至全屏，桌面保留右侧面板。
- 文件夹操作在触屏上常显，桌面悬停或键盘聚焦时显示；独立按钮和菜单行在手机至少 48px。正文点词保持自然排版，并支持键盘打开。
- 关闭后台 YouTube 导入或分析视图不取消任务；取消沿用各任务按钮。正在解析/写入的文件导入确认不通过关闭接口撤销。文件夹创建、重命名及词语备注保存失败保留输入。
- 五种主题保留，新增交互使用语义变量；重点检查 ocean 与 midnight。布局使用动态视口高度，支持减少动态效果。

## Android 接入及未完成的原生验收

`src-tauri/android-template/MainActivity.kt` 保留凭据上下文初始化，增加：

1. Android 返回先隐藏 IME，然后交给前端最上层弹层/页面/文件夹协调器；根层交还系统。阅读顶部返回通过本地 bridge 走同一路径。
2. 原生容器处理系统栏、刘海和 IME 占用，向 WebView 传递已扣除的 inset；前端识别 native 标记后不重复补偿安全区。
3. 根据 midnight 切换系统栏图标及容器背景。

inset 转发依据 [Android WebView 官方说明](https://developer.android.com/develop/ui/views/layout/webapps/understand-window-insets)。

本机 Android SDK 与 Rust Android target 可用，但缺少 NDK/command-line tools；Android 初始化因此未完成，没有成功编译或启动本次 APK。浏览器窄屏检查仅证明布局与前端交互，不能替代 Android 验收。macOS/Windows 原生壳亦未在本轮逐项人工验收。

后续需在模拟器或真机核验：手势返回、三键返回、软键盘首次返回收起、弹层嵌套返回、根层退出、系统栏/刘海无重复留白、横竖屏旋转，以及键盘打开时输入与操作按钮可达。桌面需在原生壳复核 Tab、Escape、阅读和复习原有快捷键。

## 文件卡片设计落实

- 文件信息集中在卡片上方，学习进度、移动和删除在下方并排。卡片按内容自然增高，不再通过操作区自动外边距或网格拉伸产生中间留白。
- 保留原有学习指数计算和阶段颜色，用「仅单词」「单词 + 词组」说明计算范围；四种界面语言均已覆盖。
- 手机主打开按钮和移动、删除按钮的点击区域至少 48×48px；键盘打开、移动后焦点恢复、长文件名与错误信息换行已验证。
- AI 关闭时模型入口和新分析操作隐藏；已有后台分析仍提供进度、取消和结果预览。完成、失败、继续分析、重新分析、诊断复制/导出和删除进度沿用现有业务入口。
- 补充浏览器回归现为 246 项，涵盖两种重点主题、六档宽度、四种界面语言、分析中/完成/错误、关闭 AI 后的已有任务，以及默认、悬停、按下、禁用和键盘焦点状态。176 项单元测试通过，构建通过；全量 lint 无错误（30 条警告），改动组件的定向 lint 无警告。
