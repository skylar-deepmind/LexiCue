阅读位置

应用保存材料的阅读位置，从桌面或材料库再次打开即可接着读。同步收到的位置在下次打开材料时使用，不会把正在阅读的页面挪走。

旧学习历史

“设置 → 备份 → 历史记录”保留旧单词、词组与复习记录，可查看和导出；它们不会自动作为新阅读流程的活跃语境收藏。
