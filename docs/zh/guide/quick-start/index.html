快速开始

安装 LexiCue，从一份 SRT 字幕开始。本地学习无需注册账号。

下载与安装

  1. 打开版本下载页，选择对应安装包：macOS 用 DMG，Windows 用 EXE，Android 用 APK。
  2. macOS 将应用拖入“应用程序”；Windows 运行安装程序；Android 按设备提示授予安装权限后安装 APK。
  3. 启动应用。若系统拦截未签名安装包，请按安装指南处理。

导入第一份字幕

  1. 在“文件”页点击导入，选择一份 SRT 字幕。
  2. 检查内容预览和学习语言，确认导入。
  3. 从文件库打开刚导入的文件。

查词并完成一次复习

  1. 点击原句中的单词，查看释义。
  2. 将想记住的词标为“学习中”。
  3. 进入“复习”，回忆含义、显示答案，再按记忆程度评分。
