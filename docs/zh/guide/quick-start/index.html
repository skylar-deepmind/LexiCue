导入并打开材料

  1. 在“材料”页打开导入，选择文件，或粘贴英文正文、网页链接、YouTube 链接。
  2. 检查提取的正文；若提供页码或章节选择，按需调整后确认。点击材料卡开始阅读。

保存一次相遇

  1. 选中不懂的单词或表达，查看含义，连同原句保存；按需添加自己的注释。
  2. 在“已保存”中查找记录；当表达在后续阅读中出现时，点击高亮查看过去的语境。
