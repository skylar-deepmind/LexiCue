# 0.4.4 云同步恢复修复

旧版云端文件快照可继续包含已删除词汇的 occurrence 引用。恢复时 `local_id_for` 会过滤 tombstone，旧逻辑将其视为 `invalid_encrypted_record`，导致同一事务中的恢复全部回滚。错误转换又只保留包含 `_error` / `_failed` 的代码，把该错误误报为本机写入失败。

现在文件快照中的单词、词组引用经过单独解析：有效引用正常恢复，明确删除的引用（含别名）跳过；未知引用继续拒绝，防止静默接受不完整资料。文件正文和其余标注保留，恢复失败仍回滚。同步边界使用已知错误代码清单，移除应用上下文前缀后保留正确代码；SQLite 原文只参与诊断分类，不返回到 UI。

- 14 个已完整暂存的文件及其词汇事件在修改前可稳定复现旧引用错误，修改后全部应用通过。
