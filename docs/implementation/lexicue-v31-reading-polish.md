# 阅读交互修正：多击、功能坞、空白收起与连续换词

日期：2026-10-25。沿用 `codex/lexicue-v31-pure-b`，承接 `94ac658`。本批只调整前端交互与回归脚本，没有修改 Rust、学习数据结构或迁移规则。

## 四项实际变化

1. **多击不再产生整句、不规则的浏览器选区。** 鼠标点词只留下当前表达的应用高亮；拖动按完整词边界选择连续短语，支持正向、反向及指针捕获，不跨原句拼接表达。触屏继续使用原选择路径，键盘 Shift+方向键保留。收起时也会清理未完成的范围，晚到的松键不会重开卡片。
2. **左侧功能坞只显示图标。** 保留同一套材料、书签、导入、齿轮图标；去掉下方常驻文字，点击目标为 48×48，保留读屏名称、选中状态、导入进行中反馈和键盘焦点。手机底部导航沿用原布局。
3. **取消 44 像素的收起窄条。** 使用实际背景点击识别，左边缘、正文侧边、句间空隙、句号栏及顶部无功能空白均可收起；查词、菜单、表单、原生滚动条、拖选和卡片内部继续正常操作。连击过程中因正文让位而露出的空白不会误触收起；Esc、返回与焦点恢复保留。
4. **连续换词不再重新开合整张卡片。** 面板实例、位置与正文让位状态保持不动。下一词的解释和保存状态准备好后，再以 180 ms、4 像素的轻移淡入交接。慢查询时保留上一页与其原词标题，并暂停旧页的保存／编辑，稍后显示当前请求反馈；不先清空词义。快速点击只接收最后一次结果，个人草稿按原句位置保留，减少动态偏好关闭交接动画。

采用固定面板与内容交接来减少闪烁，不增加新的设置或关闭按钮。示例、正常阅读、保存／撤销及旧原句回顾继续使用原有真实业务能力。
