LexiCue 词典查询结果规范 V1
日期：2026-10-26
当前产品修订（2026-10-26）：停用词典录音；音标跟随已有 us/gb 偏好且保留词性分组。文字朗读使用现有 Edge TTS、本地缓存和设备语音回退。阅读首屏为词典速览，一键记下原句无需选义。下文历史设计由第十四、十五节覆盖。
状态：词典运行时约定；朗文本地优先，作者公共 API 补查（当前适配器 1.1.0），历史来源约束保留。
配套结构：dictionary-result-v1.schema.json
元数据兼容修订：1.2（2026-10-26），显式作者公共通道及已知历史公共适配器兼容；schema_version 保持 1。

一、目标与范围

服务英语阅读中的单词、短语和习语查询。中文释义优先，保留英文原释义。
朗文作为本地主来源，剑桥作为在线补查来源；两者经过各自的转换程序，输出同一种结构，使用同一个展示组件。
“标准化”统一内容类别、对应关系、来源和缺失处理，不要求两本词典有相同义项、相同译文或相同数量的例句。
第一版不增加语言选择、百科、词源、练习题等功能，也不重新逐条人工校对整本词典。

二、用户看到的内容

单词查询：
1. 查询原文和词典词头。变化形式标明关系，例如 took → take。
2. 按词典原有词条/词性分组；每组提供对应的英式、美式音标和发音（来源有则显示）。
3. 各个意思分别列出：中文释义、英文释义、适用的语法/使用场合标签。
4. 每个意思下面放其例句：英文原句、对应中文译文（有则显示）。
5. 与该意思有关的搭配、句型和简短用法说明，以及各自的例句。
6. 原词典明确提供时，可展开词形变化、完整形式、相关短语入口。
7. 来源名称、版本，以及在线条目的原文链接。

词组查询（包含短语动词、习语、搭配、固定表达）：
1. 选中的原文和词典收录形式，例如 looked the word up → look up。
2. 整个表达的中文释义、英文释义，逐个意思列出；禁止由单词释义拼出“词组释义”。
3. 词典明确标注的类型、词性、正式/口语等使用限制。类型无法确认时只显示“表达”。
4. 对应意思的英文例句与中文译文。
5. 原词典明确说明的使用结构，如 look something up、代词位置、是否可分开、固定介词。
6. 整个表达独立的音标和音频（有则显示），以及来源。
7. 若表达来自母词条的搭配/用法框，保留母词与出处；允许这样查到，不伪装为独立词头。

固定内容是词头、匹配关系、至少一条有效释义及其来源。中文是默认学习体验的优先内容；缺中文属于已知缺口，要标“仅英文”。
词性、音标、音频、例句、例句译文、搭配、语法提示等按来源提供，不把可选项强制补齐，也不画空白占位框。
完整形式（如缩写展开）是必要语义的一部分，不能只留下“……的缩写”而丢掉后面的内容。

三、共同的组织方式

查询结果 → 来源词条 → 原有词条/词性组 → 意思 → 搭配/句型、例句、用法说明。

每条意思必须单独绑定它的英文、中文、标签、例句及搭配。不能先把整页英文和中文分别收成两个列表，再按位置配对。
同一单词可以有多个同词性词条，保留原有分组，不能仅凭“拼写 + 词性”合并。
音标和词头发音跟随原有分组；record 作名词、动词时的读音不能混用。
词组不能继承母词的发音来冒充整个表达的发音，也不能拼接各个单词的音标。
用法说明可以属于整个词条、词性组或某个意思，只出现在对应范围。
搭配的例句优先放在搭配下面；同一个意思中不再重复展示为普通例句。不同意思各自收录的同句例句不能全局去重。
相关短语链接只指向新的查询，不代表两个表达意思相同。

四、查询与缺失的判定

必须保留 query.text；查询归一、词形还原和词典词头另存。大小写和标点不能在确认词条前一律抹去，例如 US/us、run-in/run in。
match.type 只描述如何匹配：原文匹配、词形变化、拼写变体、表达句型、原词典交叉引用。
source.delivery 单独描述来自本地、在线还是缓存，不能把“在线兜底”当成一种词形匹配。
表达查询必须确认找到了整个目标表达。网站返回母词条或第一个词头，不足以认定成功。
只有词典明确的别名、可靠词形规则、经过核对的表达句型可以扩展匹配；不得把任意多词选择都认作习语。
例如 look it up 应只指向“查阅”的适用意思，不能把 look up 的“好转、拜访”等意思当作本次同等匹配。
若 match.sense_ids 非空，响应只包含这些适用意思；空数组表示没有额外收窄。词形变化若确定了词性，也应限制到适用分组。
任意短语 a red car 没有整体收录时，不能把 car 的词条冠以 a red car 的标题；可另给清楚标注的单词查询建议。

结果状态：
- found：目标已确认，默认展示条目有可用中文释义，且没有已知的必要内容提取缺口。不代表已判断出“本句意思”，也不代表词典穷尽了所有用法。
- partial：目标已确认且有有效释义，但本次适用内容只有英文，或有明确的必要内容提取缺口。显示可用部分和简短缺口说明。
- not_found：查询成功完成，但没有确认到目标；不能拿不相关词条填充。
- unavailable：网络、超时、限流、解析异常、词典包未就绪等导致无法判断。不能说成“词典没收录”。
个别次义只有英文时保留该义并标注；若默认适用条目仍有可用中文，可保持 found 并提示部分意思仅英文。
缺音频、缺例句、缺例句译文本身不导致失败。空白文本转换为 null；空列表不显示。
只有例句、没有释义或可确认的整体说明时，不能作为一个已完成的词组词条。
例句无中文就展示英文；禁止拿释义的中文充当例句翻译。
本地已有部分结果而在线失败时，保留本地内容，并提示在线补查暂不可用。

五、本地朗文的接入约定

当前验证版本：review-edition-v5-quick/longman6-reviewed.sqlite。
正式打包时固化本地发布版本；开发机路径不是运行时依赖。

查询：先处理精确查询，再用 reviewed_lookup、reviewed_query_senses 及可靠词形规则；原词典重定向使用 resolved_source_aliases，限制跳转次数，拒绝循环。
词形补充修订（2026-10-27）：精确词条与有证据的词形候选同时收集，精确命中不能遮住原词的完整内容。独立词条与相关原词保留各自词头、词性、音标、意思和例句；约三条速览可展示不同词头，但每条必须标明所属词头。默认条目只决定展示和有限参考节选，不代表本句判义或收藏身份。
意思/例句：双解入口使用 candidate_bilingual_senses 和 candidate_examples；需保留英文结果时再读 reviewed_senses/reviewed_examples，按修订版的可展示标记过滤。
不直接展示底层原始 senses/examples/notes；待核实、排除项不进入默认结果。
句型：reviewed_constructions；对应例句使用 reviewed_sense_construction_examples，不把跨意思汇总的例句分配给每个意思。
说明：reviewed_notes、reviewed_note_examples、reviewed_sense_notes、reviewed_inline_hints；按作用范围和 display_adopted 等适用标记转换。
标签与完整形式：保留 scoped_metadata_json、usage_annotations_json、full_forms_json 等必要内容；不能将局部标签误标为整个词条属性。
词组类型：有明确短语动词/习语等证据才设具体类型；仅有 lexunit 标记不足以一律判为习语。
音标、词头音频和词形：当前修订文字表尚不完整覆盖这些词头信息，需要从原 MDX 的对应分组补取，并解析到词典包内资源；不能从母词随意继承。
返回每个意思和例句的稳定标识，记录修订版发布号。修订过程的来源证据留在内部审校记录，不在页面堆砌技术信息。

六、在线剑桥的接入约定

当前候选项目：https://github.com/Nongfsq/cambridge-dictionary-api
源码核对日期：2026-10-26；依据 main/data.js。它抓取网页，属于非官方接口。
默认请求简体双解 en-cn。只向上游发送查询表达，不自动发送阅读材料全文或 query.context。

现有字段可转换：
- word → 候选词头；必须进一步确认是否是本次目标表达。
- pronunciation → 对应原有词条组的音标和音频；不能仅用词性字符串关联同页多个同词性词条。
- definition[].text / translation → 同一个意思的英文/中文。
- definition[].example[] → 该意思内部的例句与译文。
- definition[].source → 数据集标识；同页不同剑桥词典的数据集分开保存和展示。

自部署时必须修正的部分：
1. 在解析阶段保留目标词头/子表达、原有词条组、意思及例句的层级和稳定定位。现有接口丢失的层级，客户端只改字段名无法补回。
2. 词组先确认目标子表达，再取它的意思；不能直接把整页第一个词头与全页释义组合返回。
3. 来源有语法、句型、搭配或用法说明时，按作用范围提取；没有就返回空列表。
4. 区分真实无结果与网络超时、403、429、上游异常、页面结构变化。现有代码把多种请求失败当作 404，需要改正。
5. 现有 verbs 来自 Simple Wiktionary，V1 不把它标成剑桥数据；暂不接入这个字段。
6. 缓存键保留词条身份，不能用统一下划线替换所有标点导致键碰撞；请求路径正确编码。
7. 保存原文链接、数据集、抓取时间和转换程序版本；不能因网页本次没抓全就覆盖更完整的有效缓存。

七、本地与在线如何一起工作

流程：查询原文 → 定位目标 → 本地转换 → 检查规范 → 展示；必要时在线补查 → 在线转换 → 同样检查 → 同样展示。

默认先查朗文。本地找不到目标、只有英文或已知关键缺口时尝试剑桥；也允许用户主动“查看剑桥”。
两种来源都存在时保留为两个来源词条。页面同一时间以一个来源为主，另一来源按需展开，避免并排堆满重复释义。
在线补查得到更完整双解时可以将剑桥设为本次默认来源，同时保留朗文入口。
不能将朗文的英文释义与剑桥的中文拼成一个意思，也不能混用两本词典的例句。
已经在审校版中确认、留有证据的修复属于固定版本内容；它与查询时临时跨词典拼接不同。
个人解释、AI 结合上下文的说明另存和明确标注，不混入词典释义或伪装成词典原文。

八、统一结构和校验边界

配套 JSON Schema 固定字段、层级、类型和空值规则，拒绝随意增加字段；只输出纯文本及受控资源地址，不输出原网站 HTML/CSS。
两套转换程序都输出这一结构，页面只读取标准结构，不直接读取 MDX HTML 或剑桥原始响应。
Schema 只能检查结构，不能证明翻译正确。转换后还必须做以下语义检查：
- 默认条目存在；所有条目、组、意思、例句、说明和句型标识在对应来源范围内无冲突。
- 每条英文/中文/例句/标签来自同一对应单位；没有跨来源或跨意思混配。
- 确认匹配目标；sense_ids 都属于当前条目，且返回意思严格遵循该范围。
- 表达有整体释义或明确的整体说明；词头与原查询有可证明的对应关系。
- 来源/版本/原始定位保留；资源路径限于安装词典包或获准的来源，不能读任意本地文件。
- 缺口和错误状态准确；已知排除项不通过换一个来源标签重新进入结果。

entry.id、group.id、sense.id 等标识必须带来源/版本命名空间；无法取得原生标识时，用来源定位生成确定性标识，不能仅靠全页数组序号。
source.release 表示本地审校发布号；在线源没有发布号则为 null，不能把转换程序版本伪装为词典版本。
source.adapter_version 独立记录转换程序版本；retrieved_at 记录在线内容抓取时间，缓存读取时保留原抓取时间。
缓存保留完整来源词条。look it up 等查询的意思限制独立应用，不能把“查阅”一个意思覆盖到完整 look up 的缓存。
缓存至少区分结构版本、来源/数据集、本地发布号、转换版本和目标身份，保留大小写/标点区别；查询匹配缓存另存原查询和限制。

九、默认呈现和保存

默认先看中文，英文解释按需展开；先展示少量意思及每义 1–2 个例句，其余用带数量的“更多意思/例句”展开。
折叠只影响页面，完整数据仍保留。不能为了短页面永久截断其他意思、词性或例句。
按词典原有顺序展示，不把第一个意思自动标成“本句意思”；有可靠限制时只展示对应范围。
阅读材料的原句与词典例句分开，阅读面板以“记下”为主要操作。
新保存不要求选义：保留原表达、原句、出处和 UTF-16 选区；可附当时展示的有限词典参考节选及个人解释。explanation 可为空，词典参考不代表已确认的本句意思。历史单义项快照按原样保留。
原文 looked the word up 与规范表达 look up 都保留；更新词典不改写个人编辑，也不使旧记录失去查看/导出能力。

颜色由页面按内容角色映射，不接受来源自带颜色：词性浅紫、搭配/句型薄荷绿、表达类型浅桃、查询命中浅黄、用法提示雾蓝。
颜色仅作辅助，始终保留文字标签；不把整段释义涂满。复用主题变量，并在 default/midnight 检查默认、悬停、选中、禁用和键盘焦点的可读性。

十、实现顺序

1. 在本地服务和页面之间建立 V1 结构及运行时校验；原始来源结构留在转换程序内部。
2. 先完成朗文转换：意思/例句/句型对应、表达定位和缺失处理，再补齐词头的音标与音频读取。
3. 修正自部署剑桥服务的目标定位和分组提取，再实现剑桥转换；统一错误与缓存规则。
4. 查询页面改为读取结构化内容。当前 DictionaryDefinition 的单个例句、DictionaryEntry 的单套发音，以及 ReadingExplanation 的平铺字符串不足以承载本规范，不能只换一个数据源地址。
5. 接入同一个展示组件与保存动作；为已有保存记录保留兼容读取，避免更新词典覆盖个人内容。
6. 通过下面的轻量验收后，才切换默认本地词典和在线补查。

十一、接入完成的轻量验收

先完成两套转换与统一展示，再用已有约 100 组日常查询作固定回归；不扩大为逐条重审整本。
必须覆盖：took→take、US/us、record 不同读音组、look up/look it up、分离式短语、母词条内表达、只有英文的表达、无例句译文、无发音、任意未收录短语、多个同词性组、在线超时/限流、不同剑桥数据集、缓存范围隔离。
检查内容对应、目标匹配、缺失提示和来源；截图/交互验收需覆盖 default 与 midnight。
通过条件：无已知的错误匹配、跨意思/跨来源混配、丢失必要语义或把请求失败说成未收录；已知缺口有明确表现。
这是快速接入验收，不承诺所有词条完全无误，也不把抽查命中率当作整本准确率。

十二、作者公共 API 通道（元数据修订 1.1）

默认在线通道采用 https://dictionary-api.eliaschen.dev/api/dictionary/en-cn/{查询表达}，由原生客户端请求；只发送表达，原句和个人内容留在本机。自部署版源码及其旧快照继续保留。

当前查询通道固定 source.access_channel=author_public_api、source.adapter_version=cambridge-public-v1.1.0、source.service_url=https://dictionary-api.eliaschen.dev。source.dataset=Cambridge Dictionary (author public API)，只描述实际访问通道，不冒充已识别原站子词典；edition、release 为 null。
公共响应未提供原词条链接及原抓取时间，本通道 entry_url、retrieved_at 必须为 null；不得构造链接或把本机时间填入 retrieved_at。新增 received_at 记录本机收到响应的 RFC3339 时间，缓存继续保留这次接收时间；界面标为“查询获取时间”，并说明原词条链接和原网页抓取时间未知。
以上例外仅用于同时满足固定通道、适配器、服务来源及接收时间的公共结果。其他 Cambridge 结果仍要求原链接与原抓取时间；朗文发布号和全部既有约束不变。任意新公共字段出现但缺少完整受控身份时拒绝结果。

定义对象为中英文释义与例句的最小对应单位；全局 pos 列表不能给每个意思猜词性。公开 JSON 丢失的原始分组、词组范围和来源层级不由客户端重建。词头不符或表达范围不能确认时，使用 unavailable 及原因通知，不输出词典确定未收录，也不靠关键词删义。404 同样只说明本次在线查询未获取到可靠结果。
公共适配器 V1 采用保守子集：只接纳大小写、标点和空白均精确对应的单个词元，不把首字母转小写当作已证明的句首关系，不自动重查词形；完整目标仍在词形说明中的单词可保留原说明。多词表达暂不接纳。若返回同时含明确缩写关系及多个词性而缺少逐义词头，整体拒绝，避免将不同大小写或词头的内容混存；不删除某些意思后猜补范围。原始公共 JSON 不足以证明所有隐藏的子词条边界，这些检查不构成完整的语义正确性证明。
保存快照保留公共通道、适配器、服务 URL 与接收时间，未知原链接/抓取时间在快照中按旧可选字段规则省略。旧记录缺少新增字段时维持原序列化结果、操作幂等签名、查看、备份与同步兼容。

十三、公共范围校验修订（适配器 1.1.0，元数据兼容修订 1.2）

当前公共查询/缓存只接受 cambridge-public-v1.1.0 和对应 cambridge:public:cambridge-public-v1.1.0: 标识；旧 1.0.0 缓存不能作为新查询结果重新进入页面。历史已保存的 1.0.0 快照继续保持其原适配器、ID、内容及作者公共接口来源标识，支持查看、导出、幂等、撤销、备份和同步，不重写历史。共享 Schema 仅保留这两个已知公共版本的元数据兼容；当前 Rust 与前端结果校验额外要求 1.1.0。

公共扁平返回中若同时存在有中文的释义及仅英文的释义，现有 JSON 无法证明其均属于所查词头；整个结果拒绝，不按关键词挑义或删掉看似无关部分。统一全英文的确认结果仍可返回 partial，统一双解的确认结果可接纳。这是针对丢失层级的保守规则，不保证所有双解页面均完整或完全准确。原文中英文、例句仍只在同一对象内绑定。

1.1.0 同时采用词头与原查询精确身份校验；句首大小写不同或母词替代不自动接纳。多词范围在 query 入口、缓存与 HTTP 前即返回 online_public_expression_unconfirmed，确定不支持的范围不消耗公共请求；此反馈不代表词典确定未收录。record 的历史响应因混入词组范围无法证明的内容被整包拒绝，不能以旧验证证据继续宣称当前接纳。历史记录本身保留供查看和备份。

十四、停用词典录音（2026-10-26）

当前应用只接入词典文字和音标，不加载、安装、下载、缓存或播放词典录音。朗文本地只定位文字包，既有录音包目录不参与发现和校验，也不产生录音缺失提示。开发资源链接仅指向 text-v1，原始下载资源和既有用户数据保留。
查询页保留词性分组，按现有 us/gb 朗读偏好显示 US/UK 对应音标；缺失时省略，不用另一口音替代。名词/动词不同读音各随对应词性。词典录音按钮和失败提示已移除；查询词、原句及旧版学习页统一复用现有 Edge TTS、缓存及设备语音回退。
剑桥新结果不转换录音链接；旧缓存交付应用前清除录音字段，保留音标、释义、例句、来源及时间。共享 V1 结构为兼容保留 audio 字段，当前查询均为 null。词典录音读取和缓存 IPC 命令不再注册。
历史保存快照、备份及数据库列保持兼容；本次不删除用户原始资源或历史文件。文字朗读服务与词典原录音保持独立。

十五、纯词典速览与保存语义修订（2026-10-26）

阅读首屏用约三条释义速览覆盖适用的不同词性，中文优先；仅英文的有效释义标明“仅英文”。“更多词典内容”统一展开完整适用词条组、英文解释、例句、句型、搭配、注释及准确来源。遵守 match.sense_ids 的已有范围证据；不按原句自动判义，不把第一义或历史解释冒充当前意思。
有效选区即可记下，加载、查不到、离线或公共接口失败均不阻塞保存。新保存使用可选 dictionary_reference={schema_version:1,kind:"dictionary_excerpt",headword,senses}，至多五条、每段释义至多2000字符、整体至多16KiB；当前界面只冻结当时速览的至多三条。原生端复核来源、ID与上限；过大的可选参考在前端省略，原句仍可保存。迟到结果不回写记录。旧 dictionary_snapshot 不改写，标为当时保存的释义。
收藏是原生端先归档再分页的只读视图：一个词/完整表达一张卡，原句记录的 record_id、source_key、revision、generation、删除标记和操作凭据保持原语义。身份只采用可靠词头及无歧义的历史别名；保留 US/us、run-in/run in、look/look up 的边界。删除、撤销只影响相应原句。
再次遇见只表示“这个词记过”，仅真实有效收藏触发，和词义、熟练度或网络状态无关。历史原句默认折叠，在当前词典释义之后展示。查词流程不新增自动判义、词语翻译对齐、服务、模型或相应字段；其他现有整句翻译和 AI 内容保留。

十六、词形候选与收藏身份修订（2026-10-27）

查询、收藏归档和再遇索引复用当前词典版本的离线关系。来源词形、明确的词形跳转与经过来源和形态核验的常规关系可以提供候选；候选有完整释义，不代表已经确认本句意思。原写法有独立词条，或有多个不同原词时，保留全部适用词头并按原写法收藏。纯词形跳转说明不构成独立冲突。
只有可信关系最终唯一且无独立冲突时才可自动归档和扩大再遇标记。went→go 可以成立；saw/see、left/leave、found/find、leaves/leaf/leave、axes/axe/axis、better/good/well，以及 books、running、studied、changed、gone 的独立用法须保守处理。仅收藏 see 不能标记 saw；字面收藏 saw 后可以标记 saw。
同样不能从歧义字面反向授权其另一用法的词形家族：字面收藏 saw 不等于已确认“锯”的身份，不能据此合并或提示 sawed/sawn。查词候选仍完整保留。大小写冲突由同一离线目录按批量排除项送入阅读匹配器；仅收藏 us/may 不得提示来源独立的 US/May。
原生批量再遇目录同时交付 expressions、case_exclusions 和 literal_only；无可用离线目录时 literal_only=true，归档与阅读均只按原写法匹配大小写，不因缺包扩大历史身份。该结构仅为可重建 IPC 视图，旧字符串列表 IPC 保留；不新增保存、导出、备份或同步字段。没有显式收藏的多字母全大写写法不借用小写历史；普通有证据的句首大小写仍按现有规则处理。
旧 dictionary_reference.headword、dictionary_snapshot.headword、default_entry_id 和第一条释义都不能单独授权归并。归档与安全词形索引是可失效、可重建的只读派生关系，不改写或物理合并记录；词典不可用或关系变化时安全退回原写法。新旧保存、备份、导出和同步结构保持兼容。
派生词、大小写身份、连字符、撇号和完整短语仍保留边界；不得任意去词尾或把逐词还原拼成短语。安全扩大标记与历史原句查询必须指向同一身份，删除最后一条有效原句后取消提醒。约三条速览可能包含多个词头时，可选保存节选只包含默认词头的可见释义，禁止将别的候选挂到该词头。
