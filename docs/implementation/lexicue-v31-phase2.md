# 第二批交付：纯 B 材料、导入与阅读主流程

2026-10-24，Asia/Shanghai。沿用 `codex/lexicue-v31-pure-b`，本批基于第一批提交 `2e0c8dd`。应用包版本仍为 0.4.5；PRD 3.1 是产品需求版本。

## 可操作结果

在本分支的 Tauri 开发版中，从功能坞 **导入 → 选择文件** 选择一份或多份英语 SRT，也可直接拖入文件。单份新材料写入成功后进入阅读；批量有成功项时回到材料页并保留逐文件结果。可切换画廊／列表，按原有标签筛选，从顶部 **材料 › 文件名** 返回。

点单词，或选中同一原句中的连续短语，打开同一个右侧解释区；键盘可在单词上按 Shift＋左右方向键扩展短语，释放 Shift 查询。默认使用本机英语词典，更多义项按需展开。解释缺失仍可保存原句，或补充个人解释。保存调用第一批真实事务与回执，只显示绿色已保存和撤销。从功能坞 **已保存** 可以查看、搜索、编辑、移除、撤销及返回原文。

右卡展开时正文平移，字号、行高、宽度和断行保持。桌面专用左侧空白区、Esc、系统返回均可收起；窄屏使用可收起的底部面板。词／短语、当前句可朗读和停止，同一时间只保留一个朗读任务，缺少英语声音时不阻断阅读。长材料先显示 80 句，再分段加载；本机记忆原句位置和像素偏移，支持重启继续。

设置保留界面语言、主题、备份恢复、加密同步，以及按需展开的词典、YouTube 下载设置和更新。旧 AI／模型偏好仍留在原存储中；新主流程不启动它们。旧 `/words`、`/phrases`、`/review`、`/insights` 链接转向 **设置 → 旧记录** 的只读视图。材料、所有语言旧词条、个人解释和上下文、复习计划与作答仍可查看／导出；原来缺失的原句不会补造。新材料页只列英语 SRT，旧 TXT 和其他语言材料可在旧记录查看原内容。

## 数据与实现边界

- 新导入命令只写 `files`、`segments`、原有标签关联和导入事务回执；不写旧词条、出现次数、熟练度、复习计划或作答。新阅读和保存也不调用旧 learning／review 链。
- `material_import_actions` 在同一 SQLite 事务里提交请求指纹和结果。相同操作重试返回相同回执；相同内容由事务内检测明确返回重复，保留原名称与内容。原材料已删除时，旧回执返回明确错误，避免旧重试重新创建材料。
- 进度按真实读取／解析／写入和逐文件结果显示，进度条只计算已处理文件数；没有定时百分比或人为等待。解析在 Worker 内运行。失败只重试未完成项；取消会终止未提交解析，并等待当前不可中断的读取／写入回执，成功提交的文件仍报告成功。收起导入面板不取消队列。
- 导入回执进入现有 schema 9 备份，老备份缺少该字段仍可恢复。材料继续使用现有材料快照同步；独立保存及冲突保护沿用第一批实现。
- 默认英语 ECDICT 和 PhraseDict 自动初始化；不再主动初始化其他学习语言的词典，也不再在词典就绪时重写旧英语 lemma／熟练度数据。旧表和兼容代码保留。
- 查询、保存选区和个人草稿按当前原句及 UTF-16 位置绑定；旧异步结果不会写回新选中项。保存回执丢失可以按同一操作标识重试。撤销编辑恢复后端记录及编辑器内容；撤销首次保存保留个人草稿。
- 查询明确区分词典、已有 AI、个人和未知来源；不会把逐词释义拼成短语答案，未知缓存提供者也不会被猜成 AI。YouTube 仅暴露英语主字幕和可选中文字幕；中文获取失败时保留英语结果，允许仅导入英语。

## 未完成项与风险

1. 阶段 3：再遇完整词／短语轻标记、多条旧原句回顾、提示开关，以及 10,000 条保存的匹配性能。已有保存管理复用第一批，不表示再遇能力已完成。
2. 阶段 4：最多三步可跳过的英语示例实操、引导重放、设置剩余兼容核对、目标用户试用和完整三端验收。
3. macOS／Windows／Android 安装版的文件选择、拖入、系统返回、真实英语语音及离线缺声仍需实机检查，Android 内容 URI 文件名也需核对。本批浏览器回归不冒充这些平台已验收。
4. YouTube 原有下载核心与失败测试继续通过；本批没有对真实在线视频及账户／浏览器会话做联网下载验收。
5. 非英语拦截采用结构、字符及明显外语词的保守检查。短小、模糊的拉丁字母文本不能保证完全识别；没有加入语言选择流程或额外识别服务。
6. 第一批已记录的混版本同步门槛继续有效：旧客户端不认识独立保存实体，发布前需统一客户端版本并做真实账户、多设备同步验收；本批未使用真实云端账户。
7. 本机阅读位置保存在本机，不承诺跨设备恢复。进程被强制终止或存储被清除时，尚未落盘的导入队列／草稿不会恢复；已提交材料、保存和回执由 SQLite 保护。
