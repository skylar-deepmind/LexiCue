# LexiCue v0.4.7 — 阅读、保存与返回更连贯

发布草稿，尚未公开。应用来源：`d2f415dd9a19700a13dadae0c92234f9d57a7eac`（main，PR #12 合并提交）。

## 这版可以体验什么

- 以英文阅读为中心：导入 PDF、DOCX、EPUB、Markdown、TXT、SRT、VTT，也可从正文、网页或 YouTube 链接导入，在原文旁按需查词并保存语境。
- 材料桌面保留少量正在阅读的卡片；完整材料库支持搜索、标签、排序与分页。已保存按词条聚合，例句分别分页，下滑后可用底部页码胶囊跳页。
- 查词先显示本地，用户点击后再获取在线内容，在线结果不会代替用户切换。可选择现有非官方 Cambridge 英汉接口，或 FreeDictionaryAPI.com / Wiktionary 英英接口。
- 内置 Wiktionary「日常通识」离线词典，可选装「进阶阅读」「专业参考」词典包。读音支持重复点击从头播放，加载与播放有对应反馈。
- 左滑词条后点击垃圾桶，删除该词条及全部例句、释义和笔记，并可整组撤销。删除材料仍保留已保存的原句、释义和笔记，已删除的原文无法再打开。
- 设置、已保存、材料和多层来源之间返回时恢复搜索、分页、滚动位置、展开例句与查词状态；返回采用轻微位移，减少闪烁。桌面查词抽屉垂直居中，长内容内部滚动。
- 去掉已保存行的整行蓝色按压覆盖，轻压反馈只作用于词条文字。修复 iPhone 长按入口时出现链接预览和拖拽的问题，保留普通点击与滚动。
- Mac 与 iPhone 可通过配对在可互通的局域网交换材料、语境、注释、标签和阅读位置。各端保留自己的本地资料库；这项 Apple 设备同步不适用于 Windows / Android。

## 更新与数据

请覆盖更新原有应用，保持相同应用标识与签名；不要先卸载或清空数据。建议先在「设置 → 备份与旧记录」导出备份。历史学习记录保留在旧记录入口。同步不代替备份。

iPhone 当前为本地签名实测构建，尚无公开 iPhone 安装包。macOS 日常开发签名包仅供本机试用；公开 macOS 包仍需 Developer ID 签名、公证及 Gatekeeper 验收，不能使用本机开发包替代。
